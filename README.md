# PCOS Health Navigator – Safe Space

## 📌 Project Overview

PCOS Health Navigator – Safe Space is an AI-powered health information navigator created using AWS PartyRock. It provides general educational information and helps users explore questions related to PCOS in a simple and supportive way.

## 🎯 Objective

The objective of this project is to create an easy-to-use AI application that provides general health information and encourages users to seek professional medical advice when needed.

## ☁️ Technologies Used

- AWS PartyRock
- Generative AI
- Amazon Bedrock
- Prompt Engineering

## ✨ Features

- AI-powered question and answer
- PCOS educational information
- Simple user interface
- Supportive AI responses
- Health awareness
